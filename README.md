# Análisis de la influencia del clima en la demanda eléctrica de Argentina
Trabajo académico de análisis de datos cuyo objetivo es estudiar cómo las condiciones climáticas influyen en la demanda eléctrica de Argentina.

Para el desarrollo se utilizaron datos históricos obtenidos de fuentes oficiales de CAMMESA, aplicando Python y distintas librerías para el procesamiento de datos, análisis estadístico y visualización.

El análisis se desarrolló en Google Colab, un entorno interactivo que permite consultar el código, ejecutar las celdas y reproducir paso a paso el proceso realizado.

Herramientas y tecnologías:
- Python
- Pandas
- NumPy
- SciPy
- Matplotlib
- Google Colab
Objetivo: explorar la relación entre las variables climáticas y la demanda eléctrica, identificar tendencias y patrones, y analizar los resultados mediante herramientas estadísticas y visualizaciones.
